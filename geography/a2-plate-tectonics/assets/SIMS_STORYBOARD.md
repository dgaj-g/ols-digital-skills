# Animated simulation storyboards (the "videos" of the platform)

Seven staged GSAP/SVG simulations. Shared SimPlayer: stage list, play/pause, per-stage
step buttons, scrub bar (timeline.progress), stage captions, reduced-motion fallback
(static final frame + stage text). Colour code everywhere = the CCEA drawn-diagram
convention Kathryn teaches: **blue = oceanic plate, brown = continental plate, red =
magma movement** (+ warm core-glow ramp for mantle). Every margin sim ends with
**"Now label it"** — the final frame becomes a drag-the-labels diagram-practice task
(place-all-then-check), training the drawn-diagram exam skill.

All stage text derives from the pupil workbook's process chains (extracts:
notes_fulltext.txt) — do not invent process steps.

1. **seafloor** — Sea-floor spreading & palaeomagnetism (Ch 3). Ridge cross-section:
   magma rises at rift → new basalt records current polarity (stripe) → divergence →
   polarity reversal recorded in next stripe → repeated cycles build the SYMMETRIC
   striped pattern → age-gradient overlay (youngest at ridge; rocks aging outwards;
   thin sediment near crest). Extra: magnetometer-trace toggle.
2. **constructive** — Constructive margin (Ch 6). Rising convection/hot spot warps +
   stretches lithosphere, faults → decompression melting, magma fills tension cracks
   (new crust) → isostatic rise: ridge sits 1–3 km above abyssal plain → ridge push →
   central slump = rift valley (Great Rift Valley) → ocean spills in = linear sea
   (Red Sea) → mature broad ridge (Mid-Atlantic Ridge), pillow lavas/basalt.
3. **destructive-oo** — Oceanic–oceanic destructive (Ch 7, Tonga). Pacific + Indo-
   Australian converge → denser Pacific subducts (slab pull label) → trench at the
   subduction point (Tonga Trench, ~11 km) → hydration melting from 80 km + subduction
   melting → magma rises, seafloor eruptions build an ISLAND ARC parallel to the trench
   (150+ Tongan islands) → Benioff-zone quake foci deepening away from trench (dots) →
   slab fully assimilated by 600–700 km.
4. **destructive-co** — Continental–oceanic destructive (Ch 7, Andes). Nazca subducts
   beneath South American → Peru–Chile Trench → compression buckles continental edge
   into FOLD MOUNTAINS → melting → magma penetrates continental plate → violent
   composite volcanoes (Mt Tacora, Nevado del Ruiz) → Benioff zone.
5. **collision** — Collision (Ch 8, Himalayas). Intervening ocean subducts (destructive
   phase) → ocean closes, continents meet → continental lithosphere too buoyant to
   subduct → compression; detached slab sinks + melts → crust thickens by folding +
   faulting; seafloor sediments buckle upwards = HIMALAYAS → violent shallow quakes;
   no volcanism (and why).
6. **conservative** — Conservative margin (Ch 9, San Andreas) — PLAN VIEW. Pacific
   (6 cm/yr) + North American (2 cm/yr) both moving NW → friction locks the fault;
   strain accumulates (roadside markers bend) → sudden release = earthquake (1906:
   7 m displacement, M 7.8); markers offset → cycle repeats. Inset: transform faults
   bisecting a ridge in a zig-zag. No volcanism callout.
7. **forces** — What drives the plates (Ch 5). Radioactive decay → convection cells
   (traditional view) → ridge push at the elevated ridge → SLAB PULL at subduction
   (flagged most important) → basal drag. Toggle: traditional vs modern view.
