# Vendored fonts — licences

**space-grotesk.woff2** — Space Grotesk, SIL Open Font License 1.1. The platform's
display face since the first build.

**dseg7-classic-bold.woff2** — DSEG7 Classic Bold, by keshikan (http://www.keshikan.net),
SIL Open Font License 1.1 with Reserved Font Name "DSEG". Source:
https://github.com/keshikan/DSEG (v0.46). Used for the Lesson 3 "arcade" skin's LED
scoreboard readouts — a real seven-segment face, because that is what a scoreboard is.

**caveat-bold.woff2** — Caveat Bold, The Caveat Project Authors, SIL Open Font License 1.1.
Source: https://github.com/googlefonts/caveat. Subset to Latin (U+0020–00FF plus curly
quotes and dashes) and converted to woff2 locally with fontTools. Used for the Lesson 5
"studio" skin's contract signature, so signing a contract looks like signing something.

All three licences permit embedding and redistribution in this form. The OFL requires the
Reserved Font Name to be respected: the files are not renamed as font families, only as
filenames, and the family names inside the fonts are untouched.
