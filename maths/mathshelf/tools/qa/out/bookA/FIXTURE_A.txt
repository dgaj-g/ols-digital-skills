FIXTURE_A.txt — DRAFT fixture questions for Book A's new lint rules
====================================================================
LINT-A package, 12 Sept 2026. This is a DRAFT ONLY — I do not edit
tools/qa/fixtures/plants.js; another package folds these into
FIXTURE_BOOK's own section (in the same style as the existing s2
"Ten single-fault stats questions (DESIGN §11.1)" section, which
already covers the ORIGINAL Book C rules — q101-q108 there are
untouched). Each item below is one question (or one movie), in
FIXTURE_BOOK's exact JS object shape, with a comment naming the rule
it breaks and the EXACT sentence dev/lint-content-stats.js prints for
it. Every sentence below was pasted verbatim from a real run:

  node dev/lint-content-stats.js --pack tools/qa/out/bookA/_dev_test_bookA.js

(that proof pack is a throwaway under this same directory, built only
to generate these sentences — it is not itself part of the fold-in).

All marks/units below are chosen so `checkReachableMarks` does not add
an incidental extra failure — the ONLY failure(s) listed per item are
the ones the comment names, except where noted as "co-occurring".

6. values on venn2 — the regions do not add up (own total AND circle
   totals both re-derived from the slot answers)
────────────────────────────────────────────────────────────────────
{ id: 'qA6', kind: 'values', marks: [2, 2], src: 'fixture',
  prompt: 'Complete the Venn diagram.',
  fig: { type: 'venn2', n: 100,
    circles: [{ id: 'A', label: 'Milk' }, { id: 'B', label: 'Sugar' }],
    totals: { A: 60, B: 50 } },
  slots: [
    { id: 'aOnly', label: 'Milk only', region: 'A', answer: { n: 40, d: 1 }, earns: 'method' },
    { id: 'bOnly', label: 'Sugar only', region: 'B', answer: { n: 30, d: 1 }, earns: 'method' },
    { id: 'both', label: 'Both', region: 'AB', answer: { n: 5, d: 1 }, earns: 'accuracy' },
    { id: 'out', label: 'Neither', region: 'out', answer: { n: 10, d: 1 }, earns: 'accuracy' }
  ] }                                     /* 40+30+5+10=85≠100; 40+5=45≠60; 30+5=35≠50 */

FAIL sentences (three, from the same one planted inconsistency):
  venn: the regions do not add up — the 4 regions sum to 85, not n = 100
  venn: the regions do not add up — circle A's regions sum to 45, not totals.A = 60
  venn: the regions do not add up — circle B's regions sum to 35, not totals.B = 50

(venn3 shares the identical `checkValuesVenn(book, secId, q, true)` code
path, parameterised on 8 regions and 3 circle totals instead of 4/2 — not
separately fixtured here for time, but exercised by the same function.)

12. pie — dx "PIE_PCT_NOT_DEG" equals the truth (distinguishability)
────────────────────────────────────────────────────────────────────
LEFT NOTE (read before using this one — see LINT_NOTES.md "left"
section): the percentage column (f×100/total) and the degree column
(f×360/total) use the SAME total, so for any category with f > 0 they
can only coincide if 100 = 360 — never. This distinguishability test
is therefore mathematically unreachable on any real (f > 0) pie
question; the fixture below proves the CODE PATH only, via a
degenerate all-zero-frequency, internally-inconsistent pack (which
also fires the two rules above on the same question — expected).
{ id: 'qA12', kind: 'pie', marks: [2, 2], src: 'fixture',
  prompt: 'Work out the angles.',
  cats: [{ id: 'a', label: 'Football', f: 0 }, { id: 'b', label: 'Hockey', f: 0 }],
  total: 10 }

FAIL sentences:
  pie: total = 10 does not equal Σf = 0
  pie: angles sum to 0, not 360
  dx: "PIE_PCT_NOT_DEG" equals the truth
