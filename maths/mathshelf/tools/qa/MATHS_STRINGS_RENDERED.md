# MathShelf — the rendered ceiling

Which sentences reach which surface. The walkers write this on every full run;
a sentence that turns up on a surface it has never been rendered on before is a
sentence that has moved, and a sentence that has moved has to be read again on
its new screen (DFM 172, the rendered half of the strings ledger).
