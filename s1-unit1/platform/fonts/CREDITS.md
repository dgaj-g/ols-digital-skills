# Fonts

- `fraunces-opsz72-400-700-latin.woff2`: Fraunces (72pt optical cut, variable weight 400 to 700), the latin subset from
  the Google Fonts CSS2 API. Designed by Undercase Type (Phaedra Charles, Flavia Zimbardi).
  https://github.com/undercasetype/Fraunces
  Licensed under the SIL Open Font License 1.1: https://openfontlicense.org/open-font-license-official-text/
  Copied from the MathShelf font folder (fetched there 12 June 2026). build-server.js inlines it into Index.html as a
  data URI, so the served page loads no outside file. Used for headings only; body text stays the system sans.
